# KORAS KR-GCS 그리퍼

설치는 [INSTALL.md](../../../../docs/INSTALL.md)를 따르세요.
시작 시 INIT 보정이 실행됩니다. 조 사이와 주변을 비우세요.
종료 경로는 열기와 release를 수행합니다. 잡은 물체를 먼저 처리하세요.

## 연결과 명령

손목 패스스루는 `--ee right=koras`를 사용합니다.
USB는 `--ee right=koras:/dev/ttyUSB0`을 사용합니다.
패스스루는 EE 타입 UNKNOWN과 115200 baud를 사용합니다.
포트는 한 프로세스만 사용해야 합니다.

API `set_squeeze(0~1)`에서 0은 열림, 1은 닫힘입니다.
텔레옵 주기는 12 Hz입니다. 데드밴드는 0.01입니다.
앱 E-stop은 현재 위치에서 정지합니다.
독립 조회는 `koras_gripper.py --action status`를 사용합니다.
응답이 있으면 종료 코드 0, 없으면 1입니다.
`demo`, `goto`, `open`, `close`는 실제 구동 명령입니다.

## 프로토콜

RS485 Modbus RTU, 115200 baud, 8N1, slave 1을 사용합니다.
FC16으로 주소 0x0000에 명령코드와 값의 두 레지스터를 씁니다.
FC06과 coil은 ACK를 받아도 장비가 무시한 이력이 있습니다.

| 코드 | 동작 | 값 |
| --- | --- | --- |
| 101 | INIT 보정 | 0 |
| 102 | 열기 | 0 |
| 103 | 닫기 | 0 |
| 104 | 위치 이동 | 0 닫힘~1000 열림 |
| 105~107 | 의미 미확인 | 사용하지 않음 |

상태는 FC03으로 0x000A부터 5개 레지스터를 읽습니다.
순서는 상태, 모터각, 전류 mA, RPM i16, finger_position입니다.
상태 비트는 b0 enable, b1 초기화, b5 열기, b6 닫기, b9 fault입니다.
상태맵과 코드 104는 장비 관찰에서 확인했습니다.

## 임피던스

임피던스는 실물 미검증입니다.
코드 108과 109는 켜기와 끄기입니다. 다음 INIT부터 적용합니다.
코드 110은 INIT 이후 타입과 강성을 설정합니다.
강성 범위는 1~10입니다.

| 타입 | 모델 |
| --- | --- |
| 1 | 2FPA-M-03-035/080 |
| 2 | 2FPA-M-03-035/080-CO |
| 3 | 2FST-M-04-100-HS |

타입이 다르면 의도한 임피던스가 적용되지 않을 수 있습니다.
상태 레지스터에 임피던스 활성 비트가 없으므로 ACK만으로 동작을 확정하지 마세요.
컨버터 옵션은 `--koras-impedance left=5/1,right=off` 형식입니다.
미지정 값과 명시적 off를 구분하세요.
프레임과 시작 순서 검사는 `test_koras_frames.py`에서 수행합니다.

외부 제어는 [제어권 전환](../../../../docs/CONTROL_HANDOFF.md)을 따르세요.
독립 EE 브리지는 `src/ee/tools/ee_zenoh_bridge.py`입니다.
같은 장치에 컨버터와 브리지를 동시에 연결하지 마세요.
