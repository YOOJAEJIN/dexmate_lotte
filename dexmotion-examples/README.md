# dexmotion-examples

Demo scripts showcasing the [dexmotion](https://github.com/dexmate-ai/dexmotion) Python package — motion planning, IK/FK, and obstacle avoidance for Dexmate robots.

## Install

```bash
pip install dexmotion
```

## Usage

Each script is standalone. Run any example directly:

```bash
python 1_basic.py
python 3_ik_relative.py
python 13_obstacle_avoidance_planning.py
```

Scripts are numbered roughly in order of complexity, from basic `MotionManager` setup through trajectory planning with obstacles.
